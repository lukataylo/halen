# Archived: Halen (writing assistant)

This is the original Halen — a local-AI writing assistant for the menu bar
(tone checks, typo fixes, snippets, dictation, Ask Halen). It's no longer
developed. Halen is now **Halen EQ**, a local-only conversation coach; see
the [repo root](../../README.md).

- Last release: **v0.3.0** — still downloadable from
  [GitHub Releases](https://github.com/lukataylo/halen/releases/tag/v0.3.0).
- Exact source of that release: git tag `halen-writing-v0.3.0`.
- Existing installs keep working. Their update feed (`/appcast.xml`) is left
  as-is, so nobody is auto-updated into a different app.
- The code here is kept for reference and still builds from this folder
  (`swift build`), but receives no fixes.
